##
Este TPC teve como objetivo a criação de uma página HTML para o Mosteiro de Santo André de Rendufe, um edifício situado em Rendufe - Amares classificado como Imóvel de Interesse Público. <br>
O trabalho foi realizado utilizando apenas HTML e CSS (sem JavaScript).

Assim, foram criados 5 ficheiros `.html`, cada um para explorar uma área diferente:
- `principal.html`: Página inicial com introdução e localização;
- `historia.html`: História detalhada do Mosteiro e cronologia;
- `galeria.html`: Galeria de fotografias organizadas por categorias (exterior, igreja e claustros);
- `visitas.html`: Dias e horários de visita e outras informações.
- `paroquia.html`: Atividades paroquiais e horários de celebrações.

### Para visualizar o trabalho criado basta:
1. Descarregar a pasta *"TPC4"* com todos os ficheiros HTML e imagens;
2. Abrir o ficheiro `principal.html` num browser.
